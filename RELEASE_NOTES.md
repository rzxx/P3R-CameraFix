# P3R Camera Fix Reload 2.0.1

This update adds independent camera-axis inversion controls for mouse and gamepad.

## What's New

- Added separate horizontal and vertical inversion settings for mouse input.
- Added separate horizontal and vertical inversion settings for gamepad input.
- Inversion is supported in both free-camera and spline/rail-camera areas.
- The new mouse X and gamepad inversion options are disabled by default; the existing mouse Y option remains available.

The new options are available in **Configure Mod** under the mouse and gamepad sections.
